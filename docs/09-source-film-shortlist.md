# Source film shortlist

This is a creative planning list for Video Sync scenes. It separates sources that are straightforward U.S. public-domain candidates from copyrighted films that are useful as references or require a separate usage decision. No media files from the copyrighted list have been acquired for the project.

Status is U.S.-specific. For public-domain films, use the original version and retain the source URL, scan provenance, publication year, and rights note. A later soundtrack, reconstruction, translation, color grade, or other creative addition may have its own copyright.

## Popeye boundary

Popeye's original 1929 character features are in the U.S. public domain. That does not make every later theatrical cartoon public domain. Before importing an animated short, record its title, release date, copyright notice, renewal evidence, source scan, soundtrack provenance, and any restoration additions. Treat an unverified short as copyrighted.

## Usage labels for the scene library

Each source should carry one of these labels:

- `public-domain-verified`: original work and the particular scan have been checked.
- `licensed`: permission or a usable license is recorded.
- `user-supplied`: local media supplied by the performer; rights status is not asserted by Video Sync.
- `reference-only`: visual direction for generated or independently shot footage; not packaged or distributed.
- `rights-review`: potentially usable, but no conclusion has been recorded.

Whether a performance is commercial is relevant to fair use but is not decisive by itself. Keep rights metadata separate from creative scene configuration so changing a source never requires rewriting the loop or cue structure.
