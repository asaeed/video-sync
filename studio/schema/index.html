Video Sync / Studio

Clips feed loops. Configured cues select one.

A scene owns numbered clips plus one or more visual loops. Normal deck playback holds the default loop; each configured hot cue selects another loop and leaves it active until a later cue or scene change.

A

Implemented v4 contract

The browser engine now consumes this visual-loop model directly. Raw video remains the default. A filter belongs to one timeline event, so the same clip can be raw in one loop and altered in another without changing the source media.

B

Deck-to-visual mixing

For each loaded deck, raw visual weight is channel level × crossfader gain. We normalize the two weights so visible deck opacity totals 100%. Play/pause changes motion, not this weighting: a paused deck can remain as a frozen image until faded out.

C

What we can actually receive

Ableton LinkDirect

Shared musical clock, not Rekordbox deck telemetry.

  • Tempo / BPM
  • Beat ↔ monotonic-time mapping
  • Beat alignment and phase for a chosen quantum
  • Optional shared start/stop intent
  • Peer/session connectivity
Does not identify decks, tracks, hot cues, faders, or the Rekordbox sync master.
Rekordbox MIDI outputLimited

Software-confirmed indicator states routed to MIDI equipment.

  • Mapped feature illumination on/off
  • Potential play/cue indicator feedback
  • Selected equipment destination
MIDI Learn is not a general software event socket. The tested virtual destination received no Rekordbox data.
DDJ-GRV6 MIDIConfirmed on macOS

Published controller gestures and positions.

  • Play/cue and performance-pad presses
  • Channel-fader positions
  • Crossfader position
  • Trim, EQ, and effect controls
  • Deck-specific MIDI channels
A passive second client received controls while Rekordbox played. These are performer gestures—not measured audio levels or every software-originated state change.
Video Sync bridgeDerived

Timestamped Link snapshots plus raw and normalized controller MIDI.

  • Visual deck playing/paused state
  • Loaded-track generation
  • Normalized visual opacity
  • Dominant deck
  • Scene instance and visual-loop clock
Link remains read-only. MIDI mappings come from AlphaTheta's device table and are checked against raw performance captures.
Rekordbox analysisOffline/enrichment

Useful local-library data, but no documented live API.

  • Analyzed BPM and beat grid
  • Stored hot-cue positions
  • Phrase analysis where available
  • Track identity and metadata
Useful later for authoring and reconciliation. It does not supply the live audible deck or playhead through Ableton Link.
